# `guide/14-superficies/`

One chapter per surface Umbral publishes on. The system is the same everywhere. Only the constraints
change.

| Surface | Mode | The thing that bites |
|---|---|---|
| `landing.md` | laboratorio | No nav bar. One sentence. Rows, not cards. |
| `web.md` | laboratorio | Fonts must be self-hosted, not a CDN |
| `streamlit.md` | instrumento | `primaryColor` hits every widget. `lang="en"` needs a shim. |
| `quarto.md` | laboratorio | Use the generated `_brand.yml`. `fig-alt` carries the finding. |
| `notebook.md` | laboratorio | Do not copy the old `mplstyle`. Its axis colour failed contrast. |
| `social.md` | instrumento | The card travels without its page. The source line is not optional. |
| `slides.md` | laboratorio | Nothing below 24px, ever |
| `github.md` | — | No emoji, no decorative badges, both licence files |
| `email.md` | laboratorio | No CSS variables. Inline the values copied from the build. |

Each chapter ends with a pre-publish checklist for that surface. The repo-wide short list is
`guide/CHECKLIST.md`.
